# Отчёт к лабораторной работе №6 (вариант 1)

**Тема:** Стилизация веб-приложения с использованием Bootstrap.

**Цель:** интегрировать UI-библиотеку, заменить базовые элементы интерфейса готовыми компонентами и проверить адаптивность.

**Ход работы.** Создано React-приложение портфолио. Подключены Bootstrap CSS и React Bootstrap. Навигация, кнопки, поля ввода и карточки используют компоненты библиотеки (`Navbar`, `Nav`, `Button`, `Form`, `Card`, `Container`, `Row`, `Col`). Список проектов адаптируется под ширину экрана: одна колонка на мобильных устройствах, две на планшетах и три на десктопах. Поиск фильтрует карточки.
