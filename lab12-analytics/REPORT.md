# Отчёт к лабораторной работе №12 (вариант 1)

**Тема:** Интеграция интерактивной визуализации данных.

**API:** `GET /api/analytics/summary`. MongoDB aggregation pipeline группирует проекты по категории и статусу, рассчитывает количество, средний и общий бюджет. Пример ответа:

```json
{
  "byCategory": [
    {"category":"Web app","projects":2,"averageBudget":2250,"totalBudget":4500}
  ],
  "byStatus": [
    {"status":"completed","count":2}
  ],
  "generatedAt":"2026-10-24T00:00:00.000Z"
}
```

Числа выше приведены как пример формата ответа; фактические значения зависят от данных в MongoDB.

**Визуализация:** столбчатая диаграмма сравнивает количество проектов по категориям; круговая диаграмма показывает распределение по статусам. Plotly отображает подсказки при наведении.
