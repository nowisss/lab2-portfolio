# Отчёт по лабораторной работе № 3

**Тема:** Разработка структуры веб-приложения на Angular с использованием модулей, компонентов и сервисов.  
**Вариант 1:** Портфолио фриланс-разработчика.

## Цель
Получить практические навыки модульной организации Angular-приложения, создания компонентов и предоставления данных через сервис с использованием Dependency Injection.

## Реализация
- **AppModule** — объявляет компоненты и запускает `AppComponent`.
- **HeaderComponent** — отображает название портфолио и навигацию.
- **ProjectListComponent** — внедряет `ProjectsService` через конструктор; в `ngOnInit()` получает список проектов; `*ngFor` создаёт карточку для каждого проекта.
- **ProjectCardComponent** — отображает изображение, название, категорию, год и описание проекта. Данные поступают через `@Input() project`.
- **ProjectsService** — помечен `@Injectable({ providedIn: 'root' })`; содержит четыре mock-объекта с обязательными полями `id`, `title`, `description`, `imageUrl`.
- **Стили и ассеты** — у компонентов отдельные CSS-файлы; изображения превью хранятся в `src/assets`.

## Проверка
Запуск: `npm install`, затем `npm start`; адрес приложения — `http://localhost:4200`.  
Сборка: `npm run build`.

**Скриншот работающего приложения:** после запуска откройте сайт в браузере и вставьте реальный скриншот в это место перед сдачей. Скриншот не включён автоматически, чтобы не подменять фактический результат запуска.

## Вывод
Создано Angular-приложение портфолио с модульной структурой, тремя компонентами и сервисом mock-данных. Передача данных реализована через Dependency Injection и `@Input()`, вывод коллекции — через `*ngFor`.
