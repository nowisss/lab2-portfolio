# Отчёт к лабораторной работе №7 (вариант 1)

**Тема:** Перенос веб-приложения на Next.js для SSR и SSG.

**Цель:** освоить файловый роутинг и две стратегии рендеринга.

**Реализация.** `/projects` и `/` используют `getStaticProps`: данные включаются в HTML во время сборки. `/live` использует `getServerSideProps`, возвращающий актуальное время при каждом запросе. Переходы реализованы через `next/link`.

**Примеры:** `pages/projects.jsx` — `getStaticProps`; `pages/live.jsx` — `getServerSideProps`.
