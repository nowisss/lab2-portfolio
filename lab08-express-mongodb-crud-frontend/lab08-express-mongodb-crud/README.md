# ЛР8 — Портфолио проектов (React + Express + MongoDB)

Полноценное приложение: React-интерфейс, Express REST API и MongoDB/Mongoose. Интерфейс получает данные через `/api/projects`; CRUD-операции выполняются через API и сохраняются в MongoDB.

## Требования
- Node.js 18 или новее
- MongoDB Atlas или локальный MongoDB

## Первичная настройка
1. Открой папку проекта в WebStorm.
2. Выполни `npm install`.
3. Создай `.env` в корне проекта (рядом с `package.json`) по образцу `.env.example`.
4. В `MONGODB_URI` вставь свою актуальную строку подключения. Не публикуй `.env` и не отправляй его в архивы.

## Разработка
В одном терминале:

```powershell
npm run dev
```

Открой **http://localhost:5173**. Vite обслуживает React-интерфейс, а запросы `/api` перенаправляет на Express (`http://localhost:4000`). Оба процесса запускаются одновременно.

## Запуск как единое приложение
```powershell
npm run build
npm start
```

Открой **http://localhost:4000**. Express отдаёт собранный React frontend и обслуживает API.

## API
| Метод | URL | Назначение |
|---|---|---|
| GET | `/api/health` | Состояние сервера и MongoDB |
| GET | `/api/projects` | Список проектов |
| GET | `/api/projects/:id` | Один проект |
| POST | `/api/projects` | Создание проекта |
| PUT | `/api/projects/:id` | Обновление проекта |
| DELETE | `/api/projects/:id` | Удаление проекта |

Поля проекта: `title` и `description` обязательны; `imageUrl` и `category` необязательны.

## Проверка
1. Открой сайт и нажми «Добавить проект».
2. Заполни название и описание, сохрани.
3. Убедись, что карточка появилась.
4. Обнови страницу — проект должен остаться (данные хранятся в MongoDB).
5. Проверь редактирование и удаление карточки.

Если список пустой, интерфейс покажет понятное состояние «Пока здесь тихо» — это не ошибка.
